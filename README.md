# Shade Client

Расширение для Chromium и совместимых браузеров. Подключается к Shade Server по URL и паролю, сохраняет профили сайтов и позволяет включать и отключать доступ.

## Установка

Требуется браузер на базе Chromium с поддержкой Manifest V3 и загрузки распакованных расширений.

1. В разделе **Releases** скачайте `shade-client.zip` (не `Source code`).
2. Распакуйте архив в постоянную папку.
3. Откройте `chrome://extensions` или страницу расширений своего браузера.
4. Включите режим разработчика и нажмите «Загрузить распакованное расширение».
5. Выберите папку `shade-client`, в которой находится `manifest.json`.
6. Закрепите Shade на панели расширений.

Устанавливать Node.js, Python или запускать команды не требуется.

## Использование

Откройте Shade, добавьте URL сервера и введите пароль. Разрешите доступ к выбранному сайту, если браузер запросит разрешение.

Сохранённые сайты можно открывать из списка. После истечения сессии потребуется повторный ввод пароля. Пароль не сохраняется. Доступ можно отключить для отдельного сайта или для всех сайтов сразу.

Используются обычные HTTP(S)-адреса. Для удалённых серверов необходим HTTPS. При неудачном входе открывается публичная версия сайта.

## Обновление

Скачайте новый релиз, замените файлы в папке установленного расширения и нажмите «Обновить» на странице расширений. Не меняйте путь к папке, чтобы сохранить профили.

## Сборка из исходников

Этот раздел предназначен для разработчиков. Требуется Node.js 22+ и npm.

```sh
npm install
npm run build
```

Готовое расширение находится в `dist/`. Исходники из `src/` напрямую в браузер не загружаются.

При публикации релиза GitHub Actions собирает расширение, проверяет запуск service worker в Chromium и прикрепляет `shade-client.zip` к релизу. Запуск сборки также доступен вручную на вкладке Actions. Консольные команды для установки релизного архива не нужны.
